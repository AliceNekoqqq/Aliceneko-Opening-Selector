# OC 看板娘主题精灵图

`theme-mascots.webp` 是唯一使用中的看板娘素材，4×5 网格包含 17 套主题造型，主题顺序与 `src/themes.js` 一致；最后一行仅左侧一格。尺寸 1120×1400，透明 WebP，约 384 KiB。图片由页眉、设置提示、搜索无结果和玩家悬浮入口共用，不写入角色卡或运行模块。

每格保留 OC 粉色系发色、莓紫瞳、左侧紫蝶发夹与泪滴坠；发型按主题变化，包含短发、编发盘髻、波浪、单马尾和双马尾等不同轮廓。各主题的领口、肩部、袖口、胸针和道具保留原有设计。透明底、半身构图、无白色描边。

主题编号严格按 `src/themes.js` 排列：4 列、5 行、从左到右再到下一行。CSS 以同一精灵图位置渲染所有看板娘入口。
