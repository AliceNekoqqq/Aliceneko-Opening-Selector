- 12 项 Node 回归：author、player、worldbook、worldbook-presets、person-rules、pack、observer、loader、stable-loader、confirmed-loader、update-control、runtime-version。
- 两套 Chromium UI 流程：author.ui 和 ui。覆盖同一脚本玩家／作者切换、消息 iframe 的 hostile pointer-events 样式、搜索／人物筛选、拖动浮窗、主题、世界书预设、保存与撤销、未保存提醒、音乐内嵌与保存、本机／角色卡保存、开场切换。
- 作者手机设置的更新插画、检查结果、取消更新、更新说明 dialog 的顶层显示；999999 层级的酒馆式通知实际位于设置 iframe 上方；圆角裁切、内页透明背景与 color-scheme 检查。
- 模块回归覆盖更新确认前不下载、取消记忆、缺失说明、版本不匹配、超时、通道隔离，以及更新前／下载后草稿保护。
- develop 预览构建、导入 JSON 语法、指针一致性、git diff --check。正式构建和正式指针没有修改。

浏览器测试可使用本机 Playwright Chromium；已有浏览器时用 UOS_CHROMIUM_EXECUTABLE 指定路径，特殊环境可用 UOS_CHROMIUM_ARGS 传 JSON 参数数组。本轮用 Chromium 153 与中文字体运行；临时测试依赖不写入插件或角色卡。

## 发布条件与边界

浏览器流程使用真实 DOM 与打包后的运行模块，但酒馆助手／角色保存接口是模拟实现，不等同于普通 SillyTavern 或 TauriTavern 实机验收。仍需在实际酒馆确认角色卡导出后重新导入、真实世界书保存、手机触摸拖动，以及 Tauri WebView 的弹窗和资源加载。

beta.11 改动包含 Loader：建议替换一次测试 JSON，以获得自动更新及下载后的草稿保护。旧 beta.8～beta.10 Loader 更新远程模块后只有手动入口的前置保护。首次升级／替换脚本前应先保存当前编辑。

正式发布仍须按 AGENTS.md 的隔离流程执行：实际验收通过，确定新的正式版本及对应 CHANGELOG，先发布 main 运行模块，最后更新正式指针。本轮审查不保证不存在所有 bug，且不替代实机验收。
