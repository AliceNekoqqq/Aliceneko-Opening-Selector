# 纯远程入口审查（2026-10-03）

审查基线：develop v1.0.10-beta.12，提交 0539022。本轮未改 JSON、bootstrap、运行模块、固定锚点或正式／测试运行指针，也未发布新版本。

## 结论

未发现把更新业务移到远程后造成既有功能失效。13 项 Node 回归与两套 Chromium 流程通过。本地 JSON 脚本内容 936 字节；文件 SHA-256 为 `8cce7fd478832184c9b4e24a6e217975eb3038dd0aadfa17a9bb91a3b7bd0eaa`，与审查前提交完全相同。

本地入口导入远程 bootstrap；bootstrap 从固定初始锚点或本机已确认 SHA 加载运行模块，再按通道检查更新。更新逻辑可以远程变化，无须改动现有 JSON；运行模块升级仍先展示目标版本与更新说明，等待用户确认。

Node 回归：author、player、worldbook、worldbook-presets、person-rules、pack、observer、loader、stable-loader、confirmed-loader、update-control、runtime-version、cdn-loader。历史 loader／stable-loader 用于保留旧正式格式兼容证据；当前纯远程入口由 cdn-loader 与完整链路 confirmed-loader 覆盖。

浏览器回归：author.ui、ui。浏览器加载使用真实 DOM、现有 JSON 和打包模块，但网络响应、酒馆助手与角色卡保存接口为测试替身。

## 保留的限制

- 依赖联网：bootstrap 与运行模块都必须能够取得。全部入口源不可用时只有错误提示，没有随 JSON 内嵌的离线界面。
- bootstrap 使用固定分支 URL，可能受 CDN 缓存影响；同一执行页面的 ESM 缓存也会复用已导入模块。更新远程入口不代表当前已打开脚本立即换逻辑；重新启动脚本／刷新酒馆后获取新入口，仍可能等待 CDN 缓存刷新。
- 运行指针目前从 GitHub Raw 读取；该源不可达时保留当前运行模块并显示检查失败。bootstrap 和运行模块各有三个来源，不等于更新指针也有三源。
- 本机存储禁用或被清除时，已批准版本与偏好不能可靠持久化；下次启动回到固定初始锚点，不能承诺永远不再提示。
- 远程入口会在重新加载时获取，但运行模块仍需确认才能升级。固定 `bootstrap-ref` 不随 `runtime-ref` 推进，维护者必须持续遵守。
- 正式 v1.0.12 仍是旧本地确认启动器结构，本次只审查测试通道 beta.12；没有将纯远程结构推到正式版。
- 真实 SillyTavern／TauriTavern 的 CDN／CORS／WebView、手机触摸、世界书磁盘持久化、随卡脚本导出再导入仍需实机验收；模拟回归不能替代这些结论。

长期制作原则见 AGENTS.md 第 13 节：默认不主动修改已安装 JSON，普通功能与更新逻辑通过远程兼容迭代；必须迁移本地入口时先取得明确授权。
