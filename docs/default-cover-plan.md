# 主题默认封面制作计划

用户确认：十六主题各 5 张独立绘制默认封面，共 80 张；随机分配，可重复。

- 作者上传的封面优先；默认封面只用于没有有效自定义封面的开场。
- 随机结果在同一卡片、同一主题内保持稳定，搜索、过滤、重新渲染不重新抽取。
- 默认封面不写入角色卡，不改变本地 JSON；资源随插件发布。
- 每张独立生成，横向构图，无文字、人物、UI、边框；统一压缩为 WebP。
- 按顺序完成旧档案、霓虹夜、纸与墨、黑白电影、林间信、锦书古风、星海航图、绯色契约、末日警报、深海回响、琥珀沙海、月光剧场、末班列车、极光灯塔、琉璃花房、月下神社。
- 先完成素材，再接入作者与玩家界面并检查自定义封面优先、主题切换、搜索稳定与加载失败回退。
- 完成验证后发布 develop 测试通道；不推进正式通道。

制作进度以 assets/default-covers/ 下的实际素材为准，不把未制作主题计为完成。
